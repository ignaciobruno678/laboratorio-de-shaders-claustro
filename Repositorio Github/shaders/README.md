# Materiales de MadMapper

Guarda aquí los archivos nativos `.fs`. Mantén cada material en un archivo separado y registra en el README raíz qué controles expone y cómo se relaciona con su preview web. `fibonakis-configurada.fs` es el material de la espiral dorada con flujo continuo y copias espejadas. `relampago-configurada.fs` traza una descarga entre A y B con quiebres, trim y presets de movimiento.
